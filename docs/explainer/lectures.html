Course lecture map

Each concept from the PPC 2026/27 lectures, next to where it appears in this repository and the page of this documentation that explains it. Use it to answer a question asked in the lectures' terms with a file, an ADR or a page. "Not used" says so when the repository has no counterpart, and why.

In short: the course's vocabulary, translated into this study's files and decisions.
